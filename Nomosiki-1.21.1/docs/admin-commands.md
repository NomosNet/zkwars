# Номосики: команды для админов

Шпаргалка, когда лидер фракции не может зайти, игрока надо пересадить в другой клан или армию нужно отдать другому человеку из того же клана.

Все команды ниже с пометкой **OP 2** доступны оператору и из консоли сервера. Ник ищется и среди тех, кто сейчас оффлайн, если этот игрок уже заходил на сервер. Совсем новый ник, которого сервер ни разу не видел, команда не найдёт.

Имя фракции с пробелом берите в кавычки, если после него в команде есть ещё аргумент:

```
/faction admin leader "Красное солнце" Steve
```

Если фракция — последний аргумент, кавычки не обязательны:

```
/faction admin move Steve Красное солнце
```

В чат фракции и в Discord уходит ваше имя, а не имя лидера. Игроки видят, что действие сделал админ.

---

## Сначала посмотреть

Прежде чем что-то менять, выясните, кто лидер, в сети ли он и что висит на дипломатии.

| Команда | Когда |
| --- | --- |
| `/faction admin list` | Обзор всех фракций: сколько людей и **в сети ли лидер**. С этого удобно начинать, если «клан завис». |
| `/faction admin info <игрок>` | В какой фракции человек, лидер он или рядовой, онлайн ли. |
| `/faction members <фракция>` | Полный состав с никами. Владелец помечен. |
| `/faction admin relations <фракция>` | С кем война, обычный союз и военный союз. |
| `/faction admin pending <фракция>` | Заявки, на которые может ответить только лидер: мир, союз, «встать в войну», выбор стороны. |
| `/faction wars` | Все текущие войны на сервере, без привязки к одной фракции. |
| `/nomosik squad admin list <игрок>` | Номера его отрядов. Номер из этой выдачи потом идёт в `give`. |

`pending` показывает то, что копится, пока лидера нет. Само по себе оно не истекает.

## Состав фракции

Игроки сами входят только по приглашению, и приглашать может только лидер, который сейчас на сервере. Админские команды этот круг не требуют.

| Команда | Когда использовать | Когда откажется |
| --- | --- | --- |
| `leader <фракция> <игрок>` | Лидер пропал, уехал или его аккаунт больше не играет. Новый лидер может быть оффлайн. Если он был в другом клане рядовым, его перенесут. Если он там был один, тот клан распустится. | Он уже лидер этой фракции. Или он лидер **другого** клана, где ещё есть люди: сначала назначьте лидера там. |
| `add <игрок> <фракция>` | Человека надо посадить сразу, без приглашения. Цель может быть оффлайн. | У игрока уже есть фракция. Тогда нужен `move`. |
| `move <игрок> <фракция>` | Перевод из клана в клан. Работает и во время вартайма, когда обычный `/faction leave` закрыт. | Игрок и так в этой фракции. Или это лидер, у которого ещё есть соратники: сначала `leader`, потом `move`. Если он в старой фракции один, перенос её распускает. |
| `kick <игрок>` | Убрать рядового, не дожидаясь, пока он сам выйдет. | Это лидер. Сначала назначьте другого. |
| `disband <фракция>` | Клан надо закрыть целиком, а лидер не зайдёт. Обычный роспуск бывает только если лидер сам сделает `/faction leave`. | Фракция не найдена. |

Порядок, если лидер не заходит, а клан должен жить:

1. `/faction admin list` — убедиться, что лидер оффлайн.
2. `/faction admin leader <фракция> <кто остаётся>`.
3. Дальше новый лидер ведёт дипломатию сам. Пока его нет, её ведёте вы командами из следующего раздела.

## Дипломатия без лидера

Обычные `/faction war`, `peace` и `alliance` выполняются от лица лидера и только когда он онлайн. Если его нет, заявка лежит, пока он не зайдёт. Админ действует **от имени двух фракций**, а не «от своей».

Сначала `/faction admin pending <фракция>`. Дальше два разных приёма.

**Закрыть уже существующую заявку.** Берите, когда одна сторона уже предложила мир или союз, а ответить некому.

| Команда | Что делает |
| --- | --- |
| `accept peace <фракция> <кто предложил>` | Принимает входящий мир. |
| `decline peace <фракция> <кто предложил>` | Отклоняет входящий мир. |
| `accept alliance <фракция> <кто предложил>` | Принимает входящий союз. Уровень берётся из заявки: обычный или военный. |
| `decline alliance <фракция> <кто предложил>` | Отклоняет входящий союз. |
| `accept warjoin <фракция> <агрессор>` | Союзник вступает в войну на стороне того, кого атаковали. |
| `decline warjoin <фракция> <агрессор>` | Союзник в войну не вступает. |
| `side <фракция> <агрессор> <aggressor\|defender\|neutral>` | Фракция была союзником обеих сторон и должна выбрать. `aggressor` — за напавшего, `defender` — за того, на кого напали, `neutral` — ни за кого. |

`<фракция>` здесь — та, которая **отвечает**, а не та, которая отправила заявку. Имена возьмите из строки `pending`.

**Решить сразу, без заявки.** Берите, когда договариваться уже не с кем или заявки не было.

| Команда | Что делает |
| --- | --- |
| `war <A> <B>` | Война. Военные союзники втягиваются так же, как если бы войну объявил лидер. Кулдаун в 60 секунд админу не мешает. |
| `peace <A> <B>` | Мир сразу. Вторая сторона ничего не подтверждает. |
| `alliance <A> <B>` | Обычный союз сразу. |
| `alliance <A> <B> military` | Военный союз сразу. Эти фракции потом входят в войны друг друга. |
| `break <A> <B>` | Разорвать обычный или военный союз, не дожидаясь кулдауна. |

`peace` и `alliance` не проходят, если фракции сейчас в войне друг с другом: сначала `peace`, потом союз. `war` не пройдёт, если они уже воюют или уже союзники. Союзника надо сначала развести через `break`.

## Отряды номосиков

Отряд можно отдать только игроку **той же фракции**. После передачи бойцы воюют за нового владельца и красятся в цвет его клана. Получатель может быть оффлайн: отряд будет ждать его.

Номер отряда — это номер из `/nomosik squad list` у владельца или из `/nomosik squad admin list <игрок>`.

| Кто | Команда | Когда |
| --- | --- | --- |
| Сам командир | `/nomosik squad give <номер> <игрок>` | Отдать один свой отряд соклановцу. Во время вартайма команда закрыта. |
| Админ | `/nomosik squad admin list <игрок>` | Посмотреть номера, когда владелец не на сервере. |
| Админ | `/nomosik squad admin give <откого> <номер> <кому>` | Один отряд. Отдающий может быть оффлайн. Вартайм не мешает. |
| Админ | `/nomosik squad admin giveall <откого> <кому>` | Все отряды сразу. Это случай «лидер не зайдёт, армию надо отдать тому, кто остался». |

Бойцы, которые в этот момент загружены в мире, переходят новому владельцу сразу. Если чанк с отрядом выгружен, карточка в камере может быть без портрета, но состав на месте: владельца бойцы получат, когда чанк снова загрузится.

### Тактическая камера

Тот же смысл без ввода номера.

- У командира на карточке своего отряда в правом верхнем углу золотой значок. Клик открывает онлайн-соклановцев. Клик по нику отдаёт этот отряд. Если в клане сейчас никого больше нет онлайн, список так и напишет: оффлайн-получателя укажите командой `admin give`.
- Админу над лентой карточек показываются участники **его** фракции, в том числе оффлайн. Клик по нику открывает армию этого игрока. Значок на карточке отдаёт отряд другому соклановцу, который сейчас в сети. Приказы с камеры при этом остаются приказами вашей армии, чужую ленту вы только смотрите и передаёте.

Камера показывает армии только своего клана. Чужой клан с камеры не переключить: для него есть команды `admin give`, а человека между кланами двигает `/faction admin move`.

## Короткие сценарии

**Лидер не заходит, клан жив, люди на месте.**  
`list` → `leader <фракция> <кто остаётся>`. Дипломатию, которая уже висит, закройте через `pending` и `accept` или `decline`.

**Игрока просят перевести в другой клан.**  
`info <игрок>`. Если он лидер и в клане есть другие — сначала `leader` на кого-то из своих, потом `move`. Если он один — достаточно `move`, старый клан распустится.

**Надо выдать человека в клан, а лидер спит.**  
`add <игрок> <фракция>`. Приглашение и согласие не нужны.

**Лидер не зайдёт никогда, армию надо сохранить.**  
`squad admin list <лидер>` → `squad admin giveall <лидер> <кто остаётся в том же клане>`. Потом при необходимости `leader` или `disband`.

**Две фракции застряли в войне, мириться некому.**  
`peace <A> <B>`. Это сразу мир, встречное «да» не требуется.
