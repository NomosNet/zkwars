# ZK Nomosiki Items

Fabric 1.21.1 addon: Japanese RP armor and weapons for Nomosiki (and vanilla players).

## Requirements

- Minecraft 1.21.1
- Fabric Loader
- Fabric API
- [AzureLib](https://modrinth.com/mod/azurelib) Fabric **1.21.1** (3.1.11, file `azurelib-fabric-1.21.1-3.1.11.jar`)

Nomosiki is optional. Units can wear these items through the equipment GUI.
