# Локальный плейтест матч-режима

Гоняется в одиночном мире через `.\gradlew.bat runClient` — второй клиент не нужен.

## Быстрый старт

1. `cd zkwars` → `.\gradlew.bat runClient`
2. Создай/открой мир с читами.
3. Возьми меч.
4. `/match solo` или `/match solo orc` / `/match solo dwarf`
5. Соло длится **15 минут** (`testDurationSeconds = 900` при `debugCommands`).
6. HUD слева сверху. **T** — тактическая камера.

## Управление

- Отряд пехоты и отряд **Workers** видны в RTS — марш/удержание как обычно.
- ЛКМ по **своему штабу** (флаг) в тактической камере → GUI: вкладки **Найм** и **Стройка**.
- Стройка: выбери здание → клик по земле в тактической камере → свободный рабочий идёт и ставит оболочку.
- ПКМ мечом по маяку-флагу ускоряет захват; круг на земле показывает прогресс.

## Команды

| Команда | Назначение |
|---|---|
| `/match solo [race]` | Соло против бота (15 мин) |
| `/match forfeit` | Сдаться |
| `/match status` | Фаза, таймер, точки |
| `/match recruit <role>` | Найм за авторитет (или через GUI) |
| `/match end` | Принудительный конец (OP) |
| `/match cleanup` | Зачистка сущностей (OP) |
| `/match timer set <sec>` | Тест конца по очкам (OP + debug) |
| `/match authority give <n>` | Авторитет (OP + debug) |
| `/match point own <id>` | Скип захвата (`mid`, `north`…) |
| `/match damage hq <0\|1> <amount>` | Урон штабу |

Роли: `worker`, `infantry`, `anti_armor`, `archer`, `cavalry`, `siege`, `support`, `elite`.  
Продвинутый найм требует зданий (казармы / стрельбище / конюшня / осада).

## Чеклист

1. Solo: два флага-штаба, юниты **снаружи** оболочки, Workers в армии RTS.
2. Круг захвата у маяков; меч ускоряет; hold подсвечивается.
3. GUI штаба → найм пехоты; стройка казарм → рабочий ставит здание → найм anti_armor.
4. `/match damage hq 1 2000` → победа; сущности сняты.
5. Повторный `/match solo` чистый.

## Конфиг

`config/zkwars/common.json` → `match`:

- `durationSeconds`: 2700 (45 мин, прод)
- `testDurationSeconds`: 900 (15 мин соло при debug)
- `holdSeconds`: 15
- `captureRadius`: 10
- `debugCommands`: true
