# ZK Wars

Мод для **Minecraft 1.21.1** (Fabric): армия номосиков — пехота, лучники, кавалерия и номады; отряды, тактическое RTS-командование, фракции и дипломатия.

**Версия:** 1.0.44 · **Автор:** WorldofCraft9

---

## Требования

| Компонент | Версия |
|-----------|--------|
| Minecraft | 1.21.1 |
| Fabric Loader | ≥ 0.16.14 (сборка: 0.18.4) |
| Fabric API | 0.115.6+1.21.1 |
| Java | 21 |

### Опционально

- **Lithium**, **Async** — рекомендуются для производительности

---

## Установка

1. Установите Fabric Loader для Minecraft 1.21.1.
2. Положите в папку `mods/`:
   - `zkwars-1.0.44.jar`
   - Fabric API
3. Запустите игру или сервер — конфиги создадутся автоматически.

### Сборка из исходников

```powershell
cd zkwars
.\gradlew.bat build
```

Готовый jar: `build/libs/zkwars-1.0.44.jar`

Клиент для разработки:

```powershell
.\gradlew.bat runClient
```

## Возможности

### Типы войск

| Тип | Описание |
|-----|----------|
| **Пехота** | Ближний бой, меч и щит |
| **Лучник** | Дальний бой |
| **Кавалерист** | Конный ближний бой |
| **Номад** | Конный лучник |

У каждого типа — свои текстуры, поведение в бою и пресеты построений.

### Найм и управление воином

- **ПКМ** по свободному номосику (пустая рука) — экран найма за **10 изумрудов**.
- После найма воин автоматически попадает в отряд.
- **ПКМ** по своему воину (пустая рука) — вкл/выкл следование.
- **Shift + ПКМ** по своему воину — GUI снаряжения, поведения, смены отряда и имени.

### Отряды

- До **48** бойцов в отряде.
- Создание, переименование, иконка, расформирование — через GUI (**J**) или команды `/nomosik squad`.
- Приказы: следовать, удерживать, марш к точке, атака зоны.
- Построения: линия, квадрат, клин, кольцо, колонна и др.
- Режимы боя: **Пассив**, **Нейтрал**, **Агрессия**, **Рейд**.

### RTS-командование

Тактический режим в духе RTS: приказы в мире, боевой HUD, тактическая камера, мультивыбор отрядов, waypoints, сдвиг строя.

Подробный чеклист для тестирования: [`docs/rts-testing-guide.md`](docs/rts-testing-guide.md)

### Фракции и дипломатия

- Создание фракции, приглашения (кнопки в чате или меню **O**), цвет, участники — GUI (**O**) или `/faction`.
- Союзы: запрос, принятие, отклонение, разрыв.
- Война и мир между фракциями; каскадные войны при объявлении.
- Friendly fire отключён между союзниками; номосики учитывают дипломатические отношения владельца.

### Discord-уведомления (сервер)

События дипломатии (война, мир, союзы) можно дублировать в Discord через Incoming Webhook. Настройка в `config/nomosiki-server.json` → секция `discord`. Подробнее: [`docs/discord-diplomacy-notifications-plan.md`](docs/discord-diplomacy-notifications-plan.md)

## Быстрый старт

1. Найдите или призовите номосика, **ПКМ** — наймите за изумруды.
2. Или (с OP уровня 2): `/nomosik squad spawn_test` — тестовый отряд из 10 пехотинцев.
3. **R** — экран командования отрядами.
4. **U** — боевой HUD.
5. **T** — тактическая камера: **ПКМ** — марш, **Ctrl+ПКМ** — атака зоны. **F** — удержание позиции. **R** — экран командования.

## Горячие клавиши

Клавиши по умолчанию; все переназначаются в настройках управления (категории **Nomosiki** и **Nomosiki RTS**).

| Клавиша | Действие |
|---------|----------|
| **R** | Экран командования отрядами / меню воина |
| **O** | Меню фракции |
| **J** | Список отрядов (редактирование) |
| **U** | Боевой HUD |
| **V** | Мини-радар |
| **Y** | Фильтр класса войск |
| **T** | Тактическая камера |
| **F** | Удержать отряд |
| **G** | Удержание огня / огонь на поражение (лучники, номады) |
| **B** | Боевой пресет построения |
| **Tab** | Смена построения |
| **Alt+1/2/3/4** | Стойка: Пассив / Нейтрал / Агрессия / Рейд |
| **Ctrl+1–9** | Быстрый выбор активного отряда |
| **`]` / `[`** | Шаг строя вперёд / назад |
| **ПКМ** (такт. камера) | Марш к точке |
| **Shift+ПКМ** (такт. камера) | Добавить waypoint |
| **Ctrl+ПКМ** (такт. камера) | Атака зоны |
| **Ctrl+J+ПКМ** (такт. камера) | Strategic fire (лучники) |

## Команды

### Отряды (`/nomosik squad`)

| Команда | Описание |
|---------|----------|
| `create <тип> [имя]` | Создать отряд (`infantry`, `archer`, `cavalry`, `nomad`) |
| `list` | Список отрядов |
| `active <номер>` | Сделать отряд активным (0 — сброс) |
| `rename <номер> <имя>` | Переименовать |
| `icon <номер> <id>` | Сменить иконку |
| `disband <номер>` | Расформировать |
| `add <номер> <uuid>` | Добавить воина по UUID |
| `add_nearby <номер> [радиус]` | Добавить своих воинов рядом |
| `leave` | Покинуть текущий отряд |
| `give <номер> <игрок>` | Отдать свой отряд соклановцу. Во время вартайма закрыто |
| `admin list <игрок>` | Отряды игрока, в том числе оффлайн (OP 2) |
| `admin give <откого> <номер> <кому>` | Передать один отряд внутри фракции (OP 2) |
| `admin giveall <откого> <кому>` | Передать все отряды игрока соклановцу (OP 2) |
| `sync` | Обновить состояние на клиенте |
| `spawn_test [тип] [число] [имя]` | Тестовый спавн (OP 2) |

### Фракции (`/faction`)

| Команда | Описание |
|---------|----------|
| `/faction` | Открыть GUI фракции |
| `members <фракция>` | Состав фракции: ники и владелец (OP 2, работает из консоли) |
| `join <фракция>` | Принять приглашение в эту фракцию |
| `decline <фракция>` | Отклонить приглашение |
| `leave` | Покинуть фракцию. Владелец распускает её |
| `war <фракция>` | Объявить войну |
| `peace <фракция>` | Заключить мир |
| `wars` | Список активных войн |
| `alliance request <фракция>` | Запрос союза |
| `alliance accept <фракция>` | Принять союз |
| `alliance decline <фракция>` | Отклонить |
| `alliance cancel <фракция>` | Отменить исходящий запрос |
| `alliance break <фракция>` | Разорвать союз |

Админские команды (`/faction admin`, OP 2, работают из консоли). Имя фракции с пробелом берите в кавычки, если после него есть ещё аргумент.

| Команда | Описание |
|---------|----------|
| `leader <фракция> <игрок>` | Назначить лидера, в том числе оффлайн |
| `move <игрок> <фракция>` | Перевести игрока. Лидера с соратниками не двигает |
| `add <игрок> <фракция>` | Принять сразу, без приглашения |
| `kick <игрок>` | Исключить рядового |
| `disband <фракция>` | Распустить фракцию |
| `list` | Фракции, число людей и онлайн ли лидер |
| `info <игрок>` | Фракция игрока |
| `relations <фракция>` | Войны и союзы |
| `pending <фракция>` | Висящие мир, союз, вступление в войну, выбор стороны |
| `accept peace\|alliance\|warjoin <фракция> <другая>` | Закрыть входящую заявку от имени фракции |
| `decline peace\|alliance\|warjoin <фракция> <другая>` | Отклонить входящую заявку |
| `side <фракция> <агрессор> <aggressor\|defender\|neutral>` | Выбор стороны |
| `war <A> <B>` | Объявить войну, кулдаун не мешает |
| `peace <A> <B>` | Мир сразу, без встречного согласия |
| `alliance <A> <B> [regular\|military]` | Союз сразу |
| `break <A> <B>` | Разорвать союз |

## Конфигурация

Конфиги создаются при первом запуске. Изменения требуют **перезапуска**.

### Клиент — `config/nomosiki.json`

| Поле | По умолчанию | Назначение |
|------|--------------|------------|
| `rtsEnabled` | `true` | RTS-ввод в мире |
| `rtsShowBattleHud` | `true` | Боевой HUD |
| `rtsTacticalCameraEnabled` | `true` | Тактическая камера |
| `rtsTacticalRaycastRange` | `256` | Дальность raycast в такт. камере |

### Сервер — `config/nomosiki-server.json`

| Поле | По умолчанию | Назначение |
|------|--------------|------------|
| `rtsCommandRange` | `128` | Макс. дистанция игрок → боец для приказа |
| `rtsMaxWaypoints` | `5` | Точек в маршруте |
| `rtsFormationStepBlocks` | `10` | Шаг сдвига строя |
| `weapons` / `armor` | — | Баланс оружия и брони (катаны и др.) |
| `discord` | `enabled: false` | Webhook-уведомления дипломатии |

Пример Discord-секции:

```json
"discord": {
  "enabled": true,
  "webhookUrl": "https://discord.com/api/webhooks/<id>/<token>",
  "language": "ru",
  "includeLeaderName": true,
  "includeServerTime": true
}
```

> **Важно:** URL webhook — секрет. Не коммитьте его в репозиторий. При утечке пересоздайте webhook в Discord.

## Разработка

Проект использует [Fabric Loom](https://fabricmc.net/develop/) с разделением `main` / `client` source sets.

```powershell
.\gradlew.bat build          # сборка
.\gradlew.bat runClient      # клиент
.\gradlew.bat runServer      # сервер
```

Официальные маппинги Mojang, Java 21.
