# ZK Wars Workers

Fabric-мод для Minecraft 1.21.1: люди-работники трудятся у блоков профессий, изнашивают инструменты и спят ночью. Курьеры носят предметы между этими блоками и сундуками.

**Версия:** 1.0.18 · **id:** `zkwars-workers`

## Требования

| Компонент | Версия |
| --- | --- |
| Minecraft | 1.21.1 |
| Fabric Loader | ≥ 0.19.3 |
| Fabric API | 0.116.17+1.21.1 |
| Java | 21 |

## Блоки

| Блок | Профессия |
| --- | --- |
| Карьер | Добыча |
| Фермер | Поле |
| Лесоруб | Дерево |
| Курятник, коровник, овчарня, свинарник | Размножение животных |

Ночью работник спит на ванильной кровати. Одна кровать — один человек.

## Свитки

- **Свиток работника** привязывает точку работы и кровать.
- **Свиток курьера** связывает до 5 рабочих блоков с сундуком и кроватью. Ночью курьер спит.

## Сборка

```powershell
.\gradlew.bat build
```

Jar: `build/libs/zkwars-workers-1.0.18.jar`
